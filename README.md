# 多模态大模型 3D 图解

用 **Three.js** 做的交互式 3D 教程：一步一步看懂大语言模型（LLM）的工作原理、它如何处理**文字 / 图片 / 语音**，以及 **Token 是怎么计算的**。

全部讲解为中文，共 **11 章、73 个步骤**。每一步都有对应的 3D 动画，可以拖动旋转、缩放观察；部分步骤带交互实验（实时分词、温度采样、梯度下降、上传图片、录音、Token 计算器等）。

## 快速开始

需要 Node.js 18+。

```bash
npm install
```

```bash
npm run dev
```

然后在浏览器打开 <http://localhost:5173>。

## 操作

- 鼠标左键拖动：旋转视角；滚轮：缩放；右键拖动：平移
- `←` / `→`（或 PageUp / PageDown）：上一步 / 下一步（章末自动进入下一章）
- `H`：隐藏 / 显示讲解面板；`F`：全屏
- 右上角"辉光"按钮可关闭后期辉光（性能较弱的电脑建议关闭）
- 网址里的 `#9-3` 表示第 9 章第 3 步，可直接分享或刷新后保持位置

## 技术栈

- [three.js](https://threejs.org/)：3D 渲染（InstancedMesh、自定义着色器、CSS2D 标签、UnrealBloom 后期）
- [GSAP](https://gsap.com/)：动画时间轴
- [gpt-tokenizer](https://github.com/niieani/gpt-tokenizer)：浏览器内运行的真实 BPE 分词器（o200k_base / cl100k_base，按需懒加载）
- [Vite](https://vite.dev/)：开发与构建

## 关于数字的准确性

- **文字 token**：使用 OpenAI 开源的 o200k_base / cl100k_base 词表，结果与对应模型完全一致；其它厂商（Anthropic、Google、阿里等）的分词器不同，数量会有差异。
- **图片 / 音频 / 视频 token**：按各家公开文档、论文与官方代码实现（核对于 2026 年 10 月），并已用官方示例验证，例如：
  - Claude：每 28×28 像素 1 个 token；标准模型长边 ≤1568 且 ≤1568 token（1920×1080 → 1,560），高分辨率模型长边 ≤2576 且 ≤4784 token；
  - GPT-4o（high）：缩放后按 512 像素切块，85 + 170 × 块数（1024×1024 → 765）；
  - Qwen2-VL / Qwen2.5-VL：patch 14 + 2×2 合并 = 每 28×28 像素 1 个 token（+2 个特殊 token）；
  - Gemini：图片 ≤384 像素 258 token，否则按块计；音频每秒 32 token；视频约每秒 263 token；
  - Whisper 编码器每秒 50 个向量，Qwen2-Audio 每秒 25 个 token；Mimi 12.5 帧/秒 × 8 层码本，EnCodec 75 帧/秒 × 8 层码本。
- 厂商会调整计费规则，计算器给出的是**估算值**，准确数字以官方文档和 API 返回的 `usage` 为准。
- 注意力权重、语义空间坐标等是为讲解而设计的**示意数据**，页面中已注明。

## 构建与部署

```bash
npm run build
```

产物在 `dist/` 目录，是纯静态文件，可部署到任意静态托管（GitHub Pages、Netlify、Nginx 等）。由于使用了 ES 模块，需要通过 HTTP 服务器访问，不能直接双击 `index.html` 打开。本地预览可用：

```bash
npm run preview
```
